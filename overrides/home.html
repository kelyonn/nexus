// eleven commands, one binary

initDetect your stack, generate a pre-filled nexus.yaml.
deployInstall platform deps, apply manifests, register with ArgoCD.
statusReplicas, ArgoCD sync/health, and pod status at a glance.
watchStream pod lifecycle events live from the Kubernetes API.
logsTail every pod's logs, prefixed by pod name. --follow streams.
chaosOne-shot pod-kill runs, or a recurring Chaos Mesh schedule.
doctorDiagnose the environment — every problem reported with a fix.
upgradeBump the image through git, the GitOps-correct way.
rollbackUndo via git revert — self-heal can't fight a revert.
destroyRemove the app's resources. --dry-run shows what would go.
dashboardLocal control panel: app grid, metrics, GitOps sync log.

Every command, flag, and default: command reference.

// the philosophy

  • Git is the source of truth Every deploy, upgrade, and rollback is a commit — not a side effect.
  • ArgoCD continuously reconciles The cluster pulls from git; nothing is pushed at it directly.
  • Self-heal respects a real revert nexus rollback reverts HEAD itself, so ArgoCD's self-heal reinforces the rollback instead of fighting it.
  • Chaos testing is one command away nexus chaos run kills a pod on purpose and waits to confirm it recovered.
  • No hidden state Watch pod events live, tail every log, read sync status — nothing happens off-screen.
